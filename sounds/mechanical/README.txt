SoundKeys ASMR Mechanical Pack v2
Original synthesized WAV effects with more distinct timbres:
Blue = bright, sharp click with a tiny double-click character
Red = soft, muted, smooth low thock
Brown = medium click with a distinct tactile bump
Black = deep, heavy low-frequency thud

Each profile contains key.wav, space.wav, enter.wav, backspace.wav, shift.wav.
Copy the four profile folders into SoundKeys/sounds/mechanical/, replacing
the existing blue/red/brown/black folders. Keep the same folder names.
These are synthesized sound effects, not physical switch recordings.
