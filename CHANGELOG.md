# Changelog

Notable changes to SoundKeys are documented here.

## [1.1.0] - 2026-11-10

### Added / improved

- Added and refined the interactive key-mapping workflow.
- Added Mechanical Mode support with selectable sound profiles and volume controls.
- Added sound-library management for importing, previewing, and removing personal audio effects.
- Added settings backup and restore support.
- Added system-tray integration.
- Added application controls for engine start/stop, mute, and volume.

### Fixed / hardened

- Improved Windows keyboard-event handling.
- Fixed automatic sound-engine startup behaviour.
- Improved playback when multiple sound effects overlap or audio channels are busy.
- Improved reliability around application startup, mode changes, and shutdown.
- Updated the Windows installer configuration for the v1.1.0 build.

### Validation

- Installer compiled successfully as `SoundKeys-Setup-1.1.0.exe`.
- User-reported validation: all five installation and runtime checks passed in VMware Pro.

## [1.0.0]

- First published installer release.
- Established the Windows installer and initial SoundKeys desktop application release.
